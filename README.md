# clubi

## Build plan

The whole app is built with **Claude Code**. **Capy** (already connected to this
GitHub repo) is used only at the very end, after the app is built.

| Stage | Tool |
|---|---|
| Build the full app (frontend, backend, data) | Claude Code |
| Final pass once the app is complete | Capy |

### Dropped from the plan

- **Convex**: not used as the backend.
- **Capy during the build**: Capy is now saved for the end instead.
- **Replit live**: not used for building or hosting.
